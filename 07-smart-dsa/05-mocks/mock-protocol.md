## The 45-Minute Protocol

### Step 1 — Pick the problem
Open the sealed mock list above. Take the next unused slot in order. Look up only the LC number — do not read any solutions, discussions, or related problems. Open the problem statement and stop.

### Step 2 — Start Fathom and set the timer
- Start Fathom recording.
- Set a hard 45-minute countdown timer on your phone or a second device. When it fires, stop — no exceptions.

### Step 3 — Narrate everything aloud
Work through the UMPIRE sequence out loud. The transcript is your deliverable; silence is a signal of no process.

| Phase | What to say aloud | Time guide |
|-------|-------------------|------------|
| **Clarify** | Restate the problem. Ask 2 disambiguating questions (even if you think you know). Confirm input/output shape, edge cases in the constraints, and whether in-place is required. | ~3 min |
| **Brute force** | Describe the naive solution in plain English. State its time and space complexity. Do not code it — just say it. | ~3 min |
| **Pattern match** | Say out loud: "This smells like ___ because ___." Name the pattern and the signal that led you there. | ~2 min |
| **Optimize** | Describe the optimized approach in English. State the new complexity. Get imaginary buy-in: "Does that approach make sense before I code?" | ~3 min |
| **Implement** | Write the code, narrating every non-trivial line. Do not go silent. | ~20 min |
| **Test** | Walk through the given examples manually. Then name two edge cases you would test and trace through them. | ~7 min |
| **Complexity wrap-up** | State final time and space complexity. Name one thing you would improve with more time. | ~2 min |

Total: ~40 min active + 5 min buffer for transitions.

### Step 4 — Stop at 45 minutes
When the timer fires, stop mid-sentence if necessary. Mark the problem as "completed" or "incomplete" in `mock-log.md`. Incomplete is not failure — it is data.

### Step 5 — Export the Fathom transcript
Export the full transcript from Fathom as plain text. Save it temporarily (you will paste it in Step 6).

## Post-Mock Checklist

Run through this before opening any external resource.

- [ ] Do not Google the problem or open LeetCode discussions yet
- [ ] Do not look at other solutions yet
- [ ] Write a 3-sentence self-reflection first:
  - What went well?
  - Where did you get stuck or slow down?
  - What would you do differently?
- [ ] Paste the transcript into `ai-reviewer-prompt.md` and get the AI review
- [ ] Log all 5 axis scores in `mock-log.md`
- [ ] Note the top 2 behaviors to drill in next week's daily problems
- [ ] Only after all of the above: look at the editorial if curious
