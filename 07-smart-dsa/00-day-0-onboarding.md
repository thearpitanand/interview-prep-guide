# Day 0 — Onboarding

Do this once, before Day 1. Budget ~90 minutes. Nothing from Day 1 onward makes full sense without it.

---

## The 6 Steps

### Step 1 — Read the 4 Method Files (~25 min)

Read all four files in `01-method/` in order. No skimming — these are short and dense.

| File | What it gives you |
|---|---|
| `feynman-protocol.md` | The 3-sentence explain-out-loud rule you follow after every single solve |
| `deliberate-practice.md` | The timer rules and re-solve protocol when you blow a budget |
| `pattern-recognition.md` | How to map a problem statement to a pattern in under 90 seconds |
| `interview-framework.md` | The UMPIRE sequence — the skeleton of every mock you will run |

You are not memorizing. You are loading the operating model so the rest of the program makes sense.

### Step 4 — Set Up the Review Log (~5 min)

Open `04-revision/review-log.md`. Read the template. Leave it open in a second tab or window — you will update it at the end of every solve session.

The review log drives Saturday's spaced-repetition queue. If it falls out of date, Saturday becomes guesswork.

---

### Step 5 — Install Fathom and Test Recording (~15 min)

Mocks start on Day 35. Set up Fathom now so you are not debugging tooling on mock day.

1. Install Fathom at [fathom.video](https://fathom.video).
2. Do a 5-minute test recording: open a terminal, narrate a problem statement out loud, stop the recording.
3. Export the transcript. Confirm the export produces readable text.
4. If the transcript is garbled or missing, resolve it now — not on Day 35.

If you prefer a different transcription tool (Otter.ai, MacWhisper, etc.), use it. The requirement is: 45-min audio → readable transcript you can paste into a chat session.

---

### Step 6 — Block Your Calendar (~10 min)

Add recurring blocks for the full 60 days:

| Slot | Days | Duration |
|---|---|---|
| Daily solve session | Mon–Fri | 2–3 hours |
| Weekly stretch + revision | Saturday | 4–5 hours |
| Flex / mock | Sunday | up to 5 hours |

Mark mock days (35, 42, 49, 52, 55, 58) as hard blocks — no rescheduling.

If you miss a weekday, do not try to cram missed problems into the next day. Move the missed problem to Saturday's flex slot and keep the daily load at 2 problems.
